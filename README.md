# VeloGenie Tech Solutions

![VeloGenie Banner](src/assets/hero-image.png)

> **Architects of the Digital Future.**  
> Speed. Logic. Aesthetics.

VeloGenie is a high-performance web engineering agency dedicated to building lightning-fast, scalable, and visually stunning digital experiences. We believe that web performance is not just a metric—it's a feature.

## 🚀 Features

-   **High-Performance Architecture:** Built with React and Vite for optimal speed and SEO.
-   **Modern Aesthetics:** Dark-themed, glassmorphism-inspired UI with smooth Framer Motion animations.
-   **Service Tiers:** Clear offerings from "LaunchPad" for startups to "Enterprise Forge" for large corporations.
-   **Dedicated Company Pages:** Detailed About Us, Case Studies, and Careers sections.
-   **Interactive Elements:** Quote request forms, service calculators, and embedded location maps.

## 🛠 Tech Stack

-   **Frontend Framework:** [React](https://reactjs.org/)
-   **Build Tool:** [Vite](https://vitejs.dev/)
-   **Styling:** CSS Modules with a custom dark theme variable system.
-   **Animations:** [Framer Motion](https://www.framer.com/motion/)
-   **Routing:** [React Router](https://reactrouter.com/)
-   **Icons:** [React Icons](https://react-icons.github.io/react-icons/)

## 📦 Installation

To set up the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone git@github.com:jayesh-2210/VeloGenie.git
    cd VeloGenie
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open the application:**
    Navigate to `http://localhost:5173` in your browser.
